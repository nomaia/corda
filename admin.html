🔑 Personal Access Token (PAT)

O PAT é necessário para fazer upload de arquivos e salvar playlists no GitHub. Ele fica salvo apenas neste navegador.

Crie em github.com/settings/tokens com permissão Contents → Read and write no repositório nomaia/corda.
Nunca compartilhe seu PAT.
